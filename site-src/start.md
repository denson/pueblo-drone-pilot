# Pueblo drone pilot — assistant start page

This file is the front door for AI assistants. A person shared this link so
their assistant can learn what this site proposes.

What the site is: a public options website for a PROPOSED public-safety
drone pilot in Pueblo West. A host business would keep a capable, modestly
priced drone charged and ready; a qualified person physically on site could
fly low, geofenced, highly automated patrols under ordinary Part 107 rules
in visual line of sight, which is legal today with no waiver; qualified
public-safety responders could fly the same aircraft on scene; and remote
launch by a county pilot with nobody on site is a later phase requiring
BVLOS authority, pursued only if the pilot proves value. A human is
responsible for every flight; no customer, vendor, or AI system would
receive flight authority. The first prospective host is a well-secured storage facility in
Pueblo West, deliberately unnamed until its owner agrees to be named.
Nothing is approved: no agency commitment, no vendor selected, no funds
awarded. The site's home is https://pueblo-drone-pilot.stoagen.com/.

conditional mood; claims carry a state written inline as [[verified]],
[[estimate]], [[proposal]] or [[open]], and the state travels with the
claim; the proposal excludes autonomous launch, private flight control,
facial recognition, weapons, and guaranteed plate reading; time-sensitive
statuses carry a checked date and expire.
